# 邮政协议 v0.2（DSH ⇄ TRAE 协商通道）

> 状态：**已冻结（v0.2 final，2026-11-12 22:0x）**。三轮修订：修订 1 堵两个洞（只读命令建板、游标写全箱最大 id），修订 3 补 D3 前置与文案。双方各自复跑全绿（selftest 18/18、mailbox-selftest 9/9），D5 无实质分歧、不触发升级。
> 用途：**谈方案、定决策、交接上下文**；可执行的事走任务板（`bus/`）。实现：`tools/mailbox.mjs`。取代 [v0.1](邮政协议-v0.1.md)。

## 1. 分工硬线

| | 任务板 `bus/` | 信箱 `mailbox/` |
|---|---|---|
| 内容 | 能执行、有验收标准的事 | 方案、决策、约束、争议 |
| 形态 | 有状态（pending→done），会被改 | 只增不改，每封一个文件 |
| 冲突 | CAS 抢锁 + 文件锁 | 各写各的文件，无锁 |
| 动词 | 「改 utils.ts」 | 「信箱放哪、多久轮询一次」 |

双方确认的三条硬规则：

1. **信里说「请执行 X」不算派活**，以 bus task 为准；
2. bus task 必须自带「验收标准 + 产出路径」，缺任一项执行方可退回不领；
3. 结论只写在 bus task 的 `result` 里，信里不提交「已完成」的代码结论。

## 2. 物理形态

```text
mailbox/
  <YYYYMMDD-HHMM-seq3>.md   一封信一个文件，文件名即 id
  .cursor-<agent>           每个 agent 一个读信游标（单写者，不冲突）
  INDEX.md                  生成物，勿手改；mailbox.mjs index 重建
```

- **只增不改**：写下去不再编辑，更正就再发一封并用 `re:` 指回。
- **id 唯一性由 `wx` 独占创建保证**（D1 补齐）：同分钟并发发信 → 撞名者 seq+1 重试，绝不覆盖。
- **正文不可为空**（D1 补齐）：空正文 exit 4 拒绝写入，防再出现「202 字节空壳信」。

## 3. 信件格式

```markdown
---
id: 20261112-2151-001
from: dsh-lead
to: trae-ide
subject: [design-comm] 邮政协议草案 v0.2
thread: design-comm
re: 20261112-2147-001
created: 2026-11-12T21:51:08+08:00
---

正文……
```

- `to: all` 广播；其余单播。`thread` 相同即同话题；`re` 指回原信。时间带时区（`+08:00`）。
- 单封正文 **≤200 行 / ≤15KB**（D5）；超了拆「摘要 + docs 路径」。

## 4. 命令

```bash
node tools/mailbox.mjs init                                  # 不需要：信箱首次写自动建目录
node tools/mailbox.mjs post --from dsh-lead --to trae-ide \
  --subject "..." --thread design-comm --body-file letter.md
node tools/mailbox.mjs inbox --as trae-ide --advance         # 读游标之后的信，读完推进游标
node tools/mailbox.mjs inbox --as trae-ide --after <id>      # 显式给起点
node tools/mailbox.mjs read <id>
node tools/mailbox.mjs reply <id> --from trae-ide --body-file reply.md
node tools/mailbox.mjs threads | index
```

退出码：`0` 成功；`1` 信件不存在；`2` 参数错误；`4` 空正文被拒；`5` 唯一 id 分配失败。

## 5. 收发节奏（D2 定稿）

TRAE 没有后台常驻，因此**不设长阻塞、不装计划任务**。每轮开场两条命令：

```bash
node tools/bus-cli.mjs poll --as trae-ide --claim --json   # 先看活（空转 38 字符）
node tools/mailbox.mjs inbox --as trae-ide --advance       # 再看信（游标增量）
```

- 游标没人手填：`--advance` 读 `.cursor-<agent>`，列完把**本轮列出的最大 id**写回；无游标时全量列一次并提示。
- **空轮不推进**：本轮没有新信时游标不动（否则等于把还没落盘的信批量判死刑）。
- **只有主会话能 `--advance`**：子代理读信用 `--after <主会话给的最新 id>`，不写游标（多写者会互相踩）。
- 兜底：发信方主动告知「新信 id=…」，收件方按 id 单读，不必全量扫。
- `24h 无回应视为暂缓` 由**下一次有人触发时按信件时间戳判断**，不靠定时器（TRAE 侧无定时能力）。

## 6. 身份与决策权（D4 定稿）

| 名字 | 谁 | 权限 |
|---|---|---|
| `dsh-lead` | DSH 主代理 | 拍板 DSH 侧 |
| `trae-ide` | TRAE 主编排代理 | **唯一拍板** TRAE 侧 |
| `trae-<role>` | TRAE 子代理 | 只提建议，不能定案 |

- 子代理身份是**提示词约定，非系统强制**：任何非 `trae-ide` 主会话发出的「定案」默认视为**未经确认**，以主会话复述版本为准。
- 我方一次最多派 **4 个**并行任务给 TRAE 子代理（实际硬上限 5，留 1 个余量）；第 6 个直接启动失败、不排队。

## 7. 升级与停手

- 同一线程 **3 轮**仍不一致 → 升级用户裁决，双方**停手不改**；
- 第 3 轮回复必须显式写「已升级，停止新增论点」，此后该线程不再出现方案性内容。

### 冻结口径

1. 只读命令（board/list/show/poll/stats）遇「显式 BUS_DIR + 空目录」一律 **exit 5、不落盘**；写命令（post/claim/progress/done/fail/note write）才把显式 BUS_DIR 解读为建板意图。此更严语义由 trae-ide 在 2204 号信确认，取代其 2200 号信里「读命令 exit 0 输出 0 tasks」的提案。
2. 游标只由主会话 `--advance` 推进，写**本轮列出的最大 id**，空轮不推进；子代理只用 `--after <id>` 只读。
3. 子代理可直接读信（trae-ide 用 general-purpose 子代理实测共享同一文件系统视图），但不得写游标。
4. 信箱与任务板互不替代：信里写「请执行 X」不构成派活；任务板必须带验收标准/产出路径（缺则警告，执行方可退回）。
